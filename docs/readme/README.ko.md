## 특징

- ⚡ **두 가지 렌더링 기반** — Takumi 또는 Forme로 PDF 생성
- 🎯 **제로 설정** — 합리적인 기본값으로 바로 사용 가능
- 👀 **실시간 미리보기** — 모든 컴포넌트와 블록을 문서에서 직접 렌더링
- 🎨 **완전한 커스터마이징** — 합리적인 props와 공유 테마, 코드는 당신의 소유
- 📦 **shadcn/ui 호환** — 동일한 레지스트리 형식과 CLI 워크플로 사용
- 🧩 **조합 가능** — 집중된 React 컴포넌트와 렌더러 프리미티브로 문서 구성
- 📄 **컴포넌트와 블록** — 테이블, 폼, 차트, 인보이스, 리포트 등

## 커뮤니티

pdfcn 커뮤니티는 [GitHub](https://github.com/shadcn-labs/pdfcn)에 있으며, 질문하고 아이디어를 공유하고 만든 것을 보여줄 수 있습니다.
