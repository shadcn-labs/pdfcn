## Características

- ⚡ **Dos motores de renderizado** — Genera PDFs con Takumi o Forme
- 🎯 **Sin configuración** — Funciona de inmediato con valores predeterminados razonables
- 👀 **Vistas previas en vivo** — Renderiza cada componente y bloque directamente en la documentación
- 🎨 **Totalmente personalizable** — Props sensatos y temas compartidos; el código es tuyo
- 📦 **Compatible con shadcn/ui** — Usa el mismo formato de registro y flujo de trabajo de la CLI
- 🧩 **Componible** — Construye documentos a partir de componentes React específicos y primitivas del renderizador
- 📄 **Componentes y bloques** — Tablas, formularios, gráficos, facturas, informes y más
