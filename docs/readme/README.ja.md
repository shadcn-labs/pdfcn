## 特徴

- ⚡ **2 つのレンダリング基盤** — Takumi または Forme で PDF を生成
- 🎯 **ゼロコンフィグ** — 妥当なデフォルト値ですぐに使える
- 👀 **ライブプレビュー** — すべてのコンポーネントとブロックをドキュメント内で直接レンダリング
- 🎨 **完全にカスタマイズ可能** — 適切な props と共有テーマ、コードは自分のもの
- 📦 **shadcn/ui 互換** — 同じレジストリ形式と CLI ワークフローを使用
- 🧩 **コンポーザブル** — 専用の React コンポーネントとレンダラープリミティブからドキュメントを構築
- 📄 **コンポーネントとブロック** — テーブル、フォーム、チャート、請求書、レポートなど
