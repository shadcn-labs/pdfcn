## Fonctionnalités

- ⚡ **Deux bases de rendu** — Générez des PDF avec Takumi ou Forme
- 🎯 **Zéro configuration** — Fonctionne immédiatement avec des valeurs par défaut sensées
- 👀 **Aperçus en direct** — Affichez chaque composant et bloc directement dans la documentation
- 🎨 **Entièrement personnalisable** — Props sensées et thèmes partagés ; le code vous appartient
- 📦 **Compatible shadcn/ui** — Utilise le même format de registre et le même flux de travail CLI
- 🧩 **Composable** — Construisez des documents à partir de composants React ciblés et de primitives de rendu
- 📄 **Composants et blocs** — Tableaux, formulaires, graphiques, factures, rapports et plus encore
