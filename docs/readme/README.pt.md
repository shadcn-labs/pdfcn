## Recursos

- ⚡ **Duas bases de renderização** — Gere PDFs com Takumi ou Forme
- 🎯 **Zero configuração** — Funciona imediatamente com padrões sensatos
- 👀 **Pré-visualizações ao vivo** — Renderize cada componente e bloco diretamente na documentação
- 🎨 **Totalmente personalizável** — Props sensatas e temas compartilhados; o código é seu
- 📦 **Compatível com shadcn/ui** — Usa o mesmo formato de registro e fluxo de trabalho da CLI
- 🧩 **Composável** — Construa documentos a partir de componentes React focados e primitivas de renderização
- 📄 **Componentes e blocos** — Tabelas, formulários, gráficos, faturas, relatórios e muito mais
