## 特性

- ⚡ **两种渲染引擎** — 使用 Takumi 或 Forme 生成 PDF
- 🎯 **零配置** — 开箱即用，提供合理的默认值
- 👀 **实时预览** — 在文档中直接渲染每个组件和代码块
- 🎨 **完全可定制** — 合理的 props 与共享主题；代码归你所有
- 📦 **兼容 shadcn/ui** — 使用相同的注册表格式和 CLI 工作流
- 🧩 **可组合** — 使用专注的 React 组件和渲染器原语构建文档
- 📄 **组件与代码块** — 表格、表单、图表、发票、报告等
