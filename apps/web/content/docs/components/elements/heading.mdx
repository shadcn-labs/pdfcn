## Installation

```bash
npx shadcn@latest add @pdfcn/elements/heading
```

Maps to Unlayer `<Heading>` (`headingType` h1-h4). Use inside
`<PDFRow>` / `<PDFColumn>` under `<PDFDocument>`. See
https://github.com/unlayer/elements.
