## Usage

```tsx
import { Spacer } from "@/components/pdf/spacer";
```

```tsx
<Spacer size={12} />
```

`size` is in points and clamped to 4–200.

## API Reference

### Spacer

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `size`  | `number` | `24`    |
| `style` | `Style`  | -       |
