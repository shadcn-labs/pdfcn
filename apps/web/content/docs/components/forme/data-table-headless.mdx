## Usage

```tsx
import {
  DataTable,
} from "@/components/pdf/data-table-headless";
```

```tsx
<DataTable columns={columns} data={data} />
```

### Compound composition

The table renders itself from `columns` and `data`. For full control, compose
the headless parts — `<DataTable.Header />`, `<DataTable.Body />`, and
`<DataTable.Footer />` render themselves from the bound props and take
explicit children for custom sections.

```tsx
<DataTable columns={columns} data={data} footer={{ total: "$1,100,200" }}>
  <DataTable.Header />
  <DataTable.Body />
  <DataTable.Footer />
</DataTable>
```

### Nested rows

Use `getSubRows` for tree/grouped data. Sub rows flatten in document order
and indent automatically; `metadata.depth` exposes the nesting level.

```tsx
<DataTable
  columns={columns}
  data={categories}
  getSubRows={(row) => row.items}
/>
```

### Adaptive cells

Cell renderers receive `{ value, row, metadata }`. Use `metadata` to adapt
content to the space available — for example, shrinking a date format on a
dense table.

```tsx
const columns = [
  {
    accessorKey: "createdAt",
    cell: ({ metadata, value }) =>
      metadata.density === "dense"
        ? formatDate(value, "short")
        : formatDate(value, "long"),
    header: "Date",
    id: "createdAt",
  },
];
```

`fitValue(value, maxChars)` truncates to a character budget, and
`metadata.maxChars` estimates the budget from the table's `width` prop.

## API Reference

### DataTable

| Prop           | Type                                     | Default                |
| -------------- | ---------------------------------------- | ---------------------- |
| `columns`      | `DataTableColumnDef<T>[]`                | -                      |
| `data`         | `T[]`                                    | -                      |
| `getSubRows`   | `(row: T) => T[] \| undefined`           | -                      |
| `density`      | `'auto' \| 'default' \| 'compact' \| 'dense'` | `'auto'`          |
| `variant`      | `'line' \| 'grid' \| 'minimal' \| 'striped' \| 'compact' \| 'bordered' \| 'primary-header'` | `'grid'` |
| `stripe`       | `boolean`                                | `false`                |
| `footer`       | `Partial<Record<string, string \| number>>` | -                    |
| `noWrap`       | `boolean`                                | `false`                |
| `emptyMessage` | `string`                                 | `'No data available'`  |
| `width`        | `number`                                 | -                      |
| `style`        | `Style`                                  | -                      |
| `children`     | `ReactNode`                              | -                      |

### DataTableColumnDef

`id` is required; values resolve via `accessorFn` or `accessorKey`
(dot paths like `"user.name"` are supported).

| Prop          | Type                                                | Default |
| ------------- | --------------------------------------------------- | ------- |
| `id`          | `string`                                            | -       |
| `header`      | `ReactNode`                                         | `id`    |
| `accessorKey` | `string`                                            | -       |
| `accessorFn`  | `(row: T) => unknown`                               | -       |
| `cell`        | `(context: { value, row, metadata }) => ReactNode`  | -       |
| `footer`      | `string`                                            | -       |
| `align`       | `'left' \| 'center' \| 'right'`                     | `'left'`|
| `width`       | `string \| number`                                  | -       |

### Cell metadata

| Field            | Type                                   | Description                             |
| ---------------- | -------------------------------------- | --------------------------------------- |
| `density`        | `'default' \| 'compact' \| 'dense'`    | Resolved density tier.                  |
| `columnCount`    | `number`                               | Columns in the table.                   |
| `columnIndex`    | `number`                               | Zero-based column index.                |
| `rowIndex`       | `number`                               | Zero-based flattened body row index.    |
| `depth`          | `number`                               | Nesting depth (0 for top-level rows).   |
| `cellFontSize`   | `number`                               | Resolved body font size (pt).           |
| `cellPaddingX`   | `number`                               | Resolved horizontal cell padding (pt).  |
| `cellPaddingY`   | `number`                               | Resolved vertical cell padding (pt).    |
| `cellWidth`      | `number \| undefined`                  | Estimated cell width (pt), needs `width`. |
| `maxChars`       | `number \| undefined`                  | Estimated character budget, needs `width`. |

### Utilities

| Function         | Signature                                          | Description                        |
| ---------------- | -------------------------------------------------- | ---------------------------------- |
| `formatValue`    | `(value: unknown) => string`                       | Display string for any cell value. |
| `fitValue`       | `(value: unknown, maxChars: number, ellipsis?: string) => string` | Truncate to a budget. |
| `estimateCellChars` | `(options) => number`                           | Estimate characters per cell.      |
