## Usage

```tsx
import { Columns } from "@/components/pdf/columns";
```

```tsx
<Columns
  left={"**Highlights**\nEnterprise plan launched in July."}
  right={"**Watch list**\nSupport response time rose to 6h."}
/>
```

Each column is multi-line text: `\n` splits lines and `**segment**` renders
bold lead-ins. Both columns wrap within their share without overflowing.

### Weighted ratios and accent rule

```tsx
<Columns ratio="2:1" accentColor="primary" left={details} right={meta} />
```

`ratio` accepts `"1:1"` (equal), `"2:1"` (wide left), or `"1:2"` (wide right).
`accentColor` draws a vertical rule between the columns, and `gap` controls
the horizontal space around it.

## API Reference

### Columns

| Prop            | Type                      | Default |
| --------------- | ------------------------- | ------- |
| `left`          | `string`                  | -       |
| `right`         | `string`                  | -       |
| `ratio`         | `'1:1' \| '2:1' \| '1:2'` | `'1:1'` |
| `gap`           | `number`                  | -       |
| `accentColor`   | `string`                  | -       |
| `renderingBase` | `'takumi' \| 'forme'`     | -       |
| `style`         | `Style`                   | -       |
