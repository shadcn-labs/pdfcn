## Installation

```bash
npx shadcn@latest add @pdfcn/pdfme/table
```

Maps to pdfme's `table` schema (`head` + `rows`). Use `toPdfmeTableSchema`
to convert head/rows when building templates manually. See
https://pdfme.com/docs/jsx.
