## Usage

```tsx
import { Title } from "@/components/pdf/title";
```

```tsx
<Title eyebrow="Invoice" title="#2026-042" />
```

### Report cover

```tsx
<Title
  eyebrow="Q3 2026"
  title="Quarterly business review"
  subtitle="Performance, customers and priorities for next quarter."
  accentColor="primary"
/>
```

### Centered

```tsx
<Title
  eyebrow="Certificate of completion"
  title="Priya Shah"
  subtitle="has successfully completed Advanced Data Visualisation"
  align="center"
/>
```

## Title vs Heading

Use `Title` once at the top of a document as its cover or hero. It renders an
optional uppercase eyebrow, a title one step larger than the theme's `h1`, and
an optional muted subtitle. Use [Heading](./heading) for section headings
inside the document.

## API Reference

### Title

| Prop           | Type                            | Default                    |
| -------------- | ------------------------------- | -------------------------- |
| `title`        | `string`                        | -                          |
| `eyebrow`      | `string`                        | -                          |
| `subtitle`     | `string`                        | -                          |
| `align`        | `'left' \| 'center' \| 'right'` | `'left'`                   |
| `accentColor`  | `string`                        | `'mutedForeground'`        |
| `color`        | `string`                        | `'foreground'`             |
| `marginBottom` | `number`                        | `theme.spacing.sectionGap` |
| `style`        | `Style`                         | -                          |
