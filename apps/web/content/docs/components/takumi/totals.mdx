## Usage

```tsx
import { Totals } from "@/components/pdf/totals/totals";
```

```tsx
<Totals
  items={[
    { label: "Subtotal", value: "$8,250" },
    { label: "Tax (20%)", value: "$1,650" },
  ]}
  totalLabel="Total due"
  total="$9,900"
/>
```

Use `align="full"` to span the parent's width, for example in a narrow receipt column:

```tsx
<Totals
  align="full"
  items={[
    { label: "Subtotal", value: "$16.50" },
    { label: "Tip", value: "$2.00" },
  ]}
  totalLabel="Paid by card"
  total="$18.50"
/>
```

## API Reference

### Totals

| Prop          | Type                                 | Default   |
| ------------- | ------------------------------------ | --------- |
| `items`       | `{ label: string; value: string }[]` | -         |
| `totalLabel`  | `string`                             | -         |
| `total`       | `string`                             | -         |
| `align`       | `'right' \| 'full'`                  | `'right'` |
| `accentColor` | `string`                             | `primary` |
| `style`       | `Style`                              | -         |

The grand-total row uses `accentColor` (a theme token such as `primary` or any colour) for its
text and top border. The block never splits across pages.
