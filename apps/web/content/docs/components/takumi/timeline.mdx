## Usage

```tsx
import { Timeline } from "@/components/pdf/timeline";
```

```tsx
<Timeline
  items={[
    { date: "2022 to now", title: "Lead Designer, Tidewave" },
    {
      date: "2019 to 2022",
      title: "Product Designer, Loom & Co",
      body: "Built the design system used by 40 engineers across 6 teams.",
    },
  ]}
/>
```

### Accent color

`accentColor` accepts a theme color token or any CSS color.

```tsx
<Timeline accentColor="success" items={items} />
<Timeline accentColor="#8b5cf6" items={items} />
```

## API Reference

### Timeline

| Prop          | Type             | Default     |
| ------------- | ---------------- | ----------- |
| `items`       | `TimelineItem[]` | -           |
| `accentColor` | `string`         | `'primary'` |
| `noWrap`      | `boolean`        | `false`     |
| `style`       | `Style`          | -           |

### TimelineItem

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `date`  | `string` | -       |
| `title` | `string` | -       |
| `body`  | `string` | -       |
