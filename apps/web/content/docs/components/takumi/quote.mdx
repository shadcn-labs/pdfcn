## Usage

```tsx
import { Quote } from "@/components/pdf/quote";
```

```tsx
<Quote
  text="Every household should be able to choose clean power, whether they own a roof or not."
  cite="Rosa Delgado, CEO of Solace Energy"
/>
```

### Centered

A centered quote replaces the accent bar with an oversized quotation mark,
which suits epigraphs and cover letters.

```tsx
<Quote
  text="Good design in healthcare is measured in anxiety removed."
  cite="A principle I design by"
  align="center"
/>
```

### Accent color

```tsx
<Quote
  text="Orbit turned a two-hour chore into a five-minute task."
  cite="A happy customer"
  accentColor="success"
/>
```

## Quote vs Text

Use `Quote` to set a single statement apart from body copy, such as a CEO quote
in a press release or a customer testimonial in a proposal. The quote renders
in larger type with an accent bar (or an oversized quotation mark when
centered) and an optional muted `— cite` attribution line. Use
[Text](./text) for regular paragraphs.

### Quote

| Prop          | Type                 | Default     |

| `text`        | `string`             | -           |
| `cite`        | `string`             | -           |
| `align`       | `'left' \| 'center'` | `'left'`    |
| `accentColor` | `string`             | `'primary'` |
| `style`       | `Style`              | -           |
