## Usage

```tsx
import { PdfProgress } from "@/components/pdf/progress";
```

```tsx
<PdfProgress
  items={[
    { label: "Design", value: 90 },
    { label: "Build", value: 65 },
    { label: "Launch", value: 20 },
  ]}
/>
```

### Without values, custom color

```tsx
<PdfProgress items={skills} showValues={false} accentColor="success" />
```

`accentColor` takes a theme color key (`primary`, `success`, `info`, …) or any CSS color. Values are clamped to 0–100.

## API Reference

### PdfProgress

| Prop          | Type             | Default     |
| ------------- | ---------------- | ----------- |
| `items`       | `ProgressItem[]` | -           |
| `showValues`  | `boolean`        | `true`      |
| `accentColor` | `string`         | `'primary'` |
| `noWrap`      | `boolean`        | `false`     |
| `style`       | `Style`          | -           |

### ProgressItem

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `label` | `string` | -       |
| `value` | `number` | -       |
