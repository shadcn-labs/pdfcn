## Usage

```tsx
import { PdfAddresses } from "@/components/pdf/addresses/addresses";
```

```tsx
<PdfAddresses
  fromLabel="From"
  from={"Northwind Studio\n12 Market Street\nLisbon, Portugal"}
  toLabel="Bill to"
  to={"Harbour & Co.\n400 Harbour Road\nSydney, Australia"}
/>
```

```tsx
<PdfAddresses
  fromLabel="Ship from"
  from={"Tallow Supply\nUnit 4, Dock Road\nRotterdam, NL"}
  toLabel="Ship to"
  to={"Jamie Ortiz\n19 Rue des Lilas\nLyon, FR"}
/>
```

## API Reference

### PdfAddresses

| Prop          | Type      | Default    |
| ------------- | --------- | ---------- |
| `from`        | `string`  | -          |
| `to`          | `string`  | -          |
| `fromLabel`   | `string`  | `'From'`   |
| `toLabel`     | `string`  | `'Bill to'` |
| `accentColor` | `string`  | theme primary |
| `style`       | `Style`   | -          |
| `renderingBase` | `'takumi'` | `'takumi'` |
