## Usage

```tsx
import { Code } from "@/components/pdf/code";
```

```tsx
<Code
  title="hello.ts"
  code={'const greeting = "Hello, pdfcn";\nconsole.log(greeting);'}
/>
```

### Syntax highlighting

Keywords, strings, numbers, and comments are painted with theme colors. The
language is inferred from a filename-like `title` (`"app.ts"` → TypeScript), or
set explicitly with `language` (`"ts"`, `"js"`, `"jsx"`, `"tsx"`, `"json"`,
`"py"`, `"sh"`, and aliases). Unknown languages fall back to plain text.

```tsx
<Code title="hello.ts" code={source} />
<Code language="shell" title="Install" code="npx shadcn@latest add …" />
```

### Truncated snippets

```tsx
<Code title="fib.ts" maxLines={5} code={source} accentColor="primary" />
```

Long listings are cut after `maxLines` lines and end with an ellipsis line;
`accentColor` draws a left rule on the block.

## API Reference

### Code

| Prop            | Type                  | Default |
| --------------- | --------------------- | ------- |
| `code`          | `string`              | -       |
| `title`         | `string`              | -       |
| `language`      | `CodeLanguage`        | -       |
| `maxLines`      | `number`              | -       |
| `accentColor`   | `string`              | -       |
| `renderingBase` | `'takumi' \| 'forme'` | -       |
| `style`         | `Style`               | -       |
