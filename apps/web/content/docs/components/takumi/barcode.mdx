## Usage

```tsx
import { Barcode } from "@/components/pdf/barcode/barcode";
```

```tsx
<Barcode data="ORB-2026-0042" format="Code128" caption="Order ORB-2026-0042" />
<Barcode data="RC004812" format="Code39" caption="Receipt RC004812" />
<Barcode data="5901234123457" format="EAN13" caption="EAN 5901234123457" />
```

Bars are drawn with PDF-safe SVG primitives. EAN-13 accepts 12 digits (check digit is
computed) or 13 digits (check digit is verified). Data that is not valid for the chosen
format renders a dashed placeholder instead of unscannable bars.

## API Reference

### Barcode

| Prop          | Type                               | Default     |
| ------------- | ---------------------------------- | ----------- |
| `data`        | `string`                           | -           |
| `format`      | `'Code128' \| 'Code39' \| 'EAN13'` | `'Code128'` |
| `caption`     | `string`                           | -           |
| `height`      | `number`                           | `44`        |
| `accentColor` | `string`                           | `'primary'` |
| `style`       | `Style`                            | -           |
