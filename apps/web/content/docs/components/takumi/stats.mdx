## Usage

```tsx
import { Stats } from "@/components/pdf/stats";
```

```tsx
<Stats
  items={[
    { label: "Revenue", value: "$1.2M", note: "+18% vs Q2" },
    { label: "Customers", value: "3,480", note: "+412 new" },
    { label: "Churn", value: "1.9%", note: "-0.4 pts" },
  ]}
/>
```

### Columns

`columns` sets how many tiles fit in a row. Extra items wrap onto the next row, and a short last row keeps the same tile width so the grid stays aligned. The value size steps down as columns increase.

```tsx
<Stats
  columns={2}
  items={[
    { label: "Timeline", value: "14 weeks", note: "Oct to Jan" },
    { label: "Investment", value: "$84k", note: "Fixed price" },
  ]}
/>
<Stats columns={4} items={items} />
```

### Accent color

The note line uses `accentColor`, which accepts a theme color token or any CSS color. Items without a `note` render only the label and value.

```tsx
<Stats accentColor="success" items={items} />
<Stats accentColor="#7c3aed" items={items} />
```

## API Reference

### Stats

| Prop          | Type          | Default     |
| ------------- | ------------- | ----------- |
| `items`       | `StatItem[]`  | -           |
| `columns`     | `2 \| 3 \| 4` | `3`         |
| `accentColor` | `string`      | `'primary'` |
| `noWrap`      | `boolean`     | `false`     |
| `style`       | `Style`       | -           |

### StatItem

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `label` | `string` | -       |
| `value` | `string` | -       |
| `note`  | `string` | -       |
