## HTML to PDF

The Elements base renders print-ready HTML. Convert it with your own
HTML-to-PDF step (Puppeteer, Playwright, …):

```ts
import { InvoiceClassicDocument } from "@/components/pdf/invoice-classic";
import { generateElementsPdf } from "@/lib/elements-generate";
import { renderElementsHtml } from "@/lib/elements-html";

const html = renderElementsHtml(<InvoiceClassicDocument />, {
  title: "Invoice",
});
const pdf = await generateElementsPdf({
  html,
  htmlToPdf: async (html) => {
    // e.g. Puppeteer: setContent(html) → page.pdf({ format: "A4" })
    throw new Error("wire up Puppeteer or Playwright here");
  },
});
```

Use `renderToHtmlParts` for custom shells and `renderToJson` for Unlayer
visual-editor round-tripping. See https://github.com/unlayer/elements and
https://docs.unlayer.com.
