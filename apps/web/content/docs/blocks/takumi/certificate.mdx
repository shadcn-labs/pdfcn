## Usage

```tsx
import { CertificateDocument } from "@/components/pdf/certificate";
```

```tsx
<CertificateDocument
  recipient="Priya Shah"
  courseTitle="Advanced Data Visualisation"
  date="13 September 2026"
  eyebrow="Certificate of completion"
  message="Awarded in recognition of outstanding work across twelve weeks of study."
  signers={[
    { name: "Dr. Helen Moore", role: "Programme Director" },
    { name: "Marcus Lee", role: "Head of Faculty" },
  ]}
/>
```

### Image watermark

Pass `watermarkImageUrl` to draw a low-opacity image (an org seal or crest)
behind the certificate content, and `watermarkOpacity` (0–1, default `0.08`)
to control its strength.

```tsx
<CertificateDocument
  watermarkImageUrl="/seal.png"
  watermarkOpacity={0.1}
/>
```

For a gift voucher instead of a formal award certificate, see
[Gift Certificate](/docs/blocks/takumi/gift-certificate).
