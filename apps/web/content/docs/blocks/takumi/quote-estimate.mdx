## Usage

```tsx
import { QuoteEstimateDocument } from "@/components/pdf/blocks/quote-estimate/quote-estimate";
```

```tsx
<QuoteEstimateDocument
  data={{
    companyName: "Brightline Builders",
    companyTagline: "Renovations and extensions",
    quoteNumber: "Q-3301",
    projectTitle: "Kitchen renovation",
    client: "Maya Patel",
    date: "September 13, 2026",
    validUntil: "October 13, 2026",
    scope: [
      "Remove existing cabinets and worktops",
      "New electrical circuits for appliances",
      "Install oak cabinets and quartz worktops",
      "Tiling, painting and final clean",
    ],
    phases: [
      { phase: "Demolition", duration: "3 days", cost: 2100 },
      { phase: "Electrical and plumbing", duration: "5 days", cost: 6400 },
      { phase: "Installation", duration: "8 days", cost: 18900 },
      { phase: "Finishing", duration: "4 days", cost: 3200 },
    ],
    adjustments: [{ label: "Contingency (5%)", value: 1530 }],
    terms: "Prices include materials and labour.",
    depositNote: "A 20% deposit confirms your start date.",
    accentColor: "#0f4c81",
  }}
/>
```

The subtotal is the sum of `phases[].cost`, and the estimated total adds every `adjustments[].value` to it. Use a negative value for discounts.

## Props

| Prop    | Type                 | Description             |
| ------- | -------------------- | ----------------------- |
| `data`  | `QuoteEstimateProps` | Quote content           |
| `theme` | `PdfcnTheme`         | Optional theme override |
