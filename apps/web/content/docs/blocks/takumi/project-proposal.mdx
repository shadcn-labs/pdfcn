## Usage

```tsx
import { ProjectProposalDocument } from "@/components/pdf/blocks/project-proposal/project-proposal";
```

```tsx
<ProjectProposalDocument
  company="Studio Kite"
  client="Greenleaf Markets"
  projectTitle="A loyalty app your shoppers will open every week"
  date="September 2026"
  stats={[
    { label: "Timeline", value: "14 weeks", note: "Oct to Jan" },
    { label: "Investment", value: "$84k", note: "Fixed price" },
    { label: "Team", value: "5 people", note: "Design and build" },
  ]}
  deliverables={[
    "Research with 20 shoppers across three stores",
    "Interactive prototype tested in-store",
    "iOS and Android apps with points and offers",
    "Launch plan and staff training",
  ]}
  milestones={[
    { date: "Oct 2026", title: "Kick-off", body: "Goals and scope agreed." },
    { date: "Dec 2026", title: "Beta", body: "First customers onboarded." },
    { date: "Jan 2027", title: "Launch", body: "Available to everyone." },
  ]}
  budget={[
    { label: "Research", value: 15 },
    { label: "Design", value: 30 },
    { label: "Engineering", value: 45 },
    { label: "Launch", value: 10 },
  ]}
  nextSteps={[
    { text: "Review proposal", done: true },
    { text: "Agree scope and budget" },
    { text: "Sign and schedule kick-off" },
  ]}
/>
```

## Notes

- **Repeating chrome.** The header (company and project title) and footer
  (company, client, date, and `Page X of Y`) are rendered as `fixed` elements,
  so they repeat on every page of multi-page proposals.
- **Caller data.** Sample data renders only when no props are passed. When you
  pass any props, content sections (stats, deliverables, milestones, budget,
  next steps) render only if you provide them, and identity fields (company,
  client, title, date) come only from your props.
