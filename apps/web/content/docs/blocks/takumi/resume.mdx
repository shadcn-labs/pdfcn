## Usage

```tsx
import { ResumeDocument } from "@/components/pdf/blocks/resume/resume";
```

```tsx
<ResumeDocument
  name="Sam Rivera"
  role="Senior Product Designer"
  contact={{
    email: "sam@rivera.design",
    location: "Lisbon, Portugal",
    website: "rivera.design",
  }}
  summary="Product designer with nine years of experience shipping consumer and B2B software. I turn fuzzy problems into simple, measurable products."
  experience={[
    {
      period: "2022 to now",
      title: "Lead Designer",
      company: "Tidewave",
      details: "Led the redesign of the mobile banking app; activation up 23%.",
    },
    {
      period: "2019 to 2022",
      title: "Product Designer",
      company: "Loom & Co",
      details: "Built the design system used by 40 engineers across 6 teams.",
    },
    {
      period: "2016 to 2019",
      title: "UX Designer",
      company: "Fieldnote",
      details: "Designed onboarding and billing for a 200k-user SaaS.",
    },
  ]}
  skills={[
    "Product strategy",
    "Interaction design",
    "Design systems",
    "Prototyping",
    "User research",
    "Figma",
  ]}
  education={[
    {
      degree: "BA Communication Design",
      school: "University of Porto",
      year: "2016",
    },
  ]}
/>
```

## One-page fit policy

The Resume block is a single-page document, so it estimates the rendered
height of your content before rendering and adapts the layout to fit one
A4 page:

- **Comfortable**: standard spacing and body text for typical resumes.
- **Compact** and **dense**: progressively tighter page padding, row
  spacing and body text size, so a long summary or several experience
  entries still fit.
- **Oversize**: content beyond the dense budget renders a visible
  "does not fit on one page" notice with the estimated overflow, instead
  of spilling onto a second page or clipping silently. Shorten the
  summary, trim experience details, or remove entries and render again.
