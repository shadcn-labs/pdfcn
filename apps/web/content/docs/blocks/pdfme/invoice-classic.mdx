## pdfme template generation

The pdfme base also exposes a native `@pdfme/jsx` template. Use
`renderToTemplate` to get a `Template + inputs` pair, then `generate()` with
the bundled plugins:

```ts
import { buildInvoiceClassicJsx } from "@/components/pdf/blocks/invoice-classic/invoice-classic.pdfme";
import { generatePdfmePdf } from "@/lib/pdfme-generate";
import { renderPdfmeTemplate } from "@/lib/pdfme-template";

const { template, inputs } = await renderPdfmeTemplate(
  buildInvoiceClassicJsx()
);
const pdf = await generatePdfmePdf({ template, inputs });
```

Try the JSX authoring layer in the [JSX Playground](https://playground.pdfme.com/jsx).
See the [pdfme docs](https://pdfme.com/docs/getting-started) and
[JSX docs](https://pdfme.com/docs/jsx) for plugins, fonts, Designer, Form and
Viewer usage.
